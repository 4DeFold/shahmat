# Пазлы

1000 реальных тактических задач из [Lichess Open Database](https://database.lichess.org/#puzzles), CC0 1.0: позиции, последовательности, рейтинги и темы опубликованы в открытом доступе. Взяты из проверенной выборки [patzer](https://github.com/SikamikanikoBG/patzer/blob/main/server/src/chess/tacticsSet.json), снимок исходной базы от 25.09.2026; сохранены исходные идентификаторы и метаданные. Задачи не генерируются из случайных партий движков. Доступно восемь тем, в каждой не менее 125 задач, один пазл может относиться к нескольким темам. Первым ходом в данных является ход соперника: позиция для решения получается после него.

Рейтинг пазлов (начальный 1500, Elo K=32), попытки и статистика сохраняются локально в браузере отдельно для каждого аккаунта и не синхронизируются между устройствами. Это не рейтинг Lichess и не игровой ЯР. Повторная попытка уже пройденной задачи не меняет рейтинг. Первое неверное решение или показ ответа фиксирует ошибку; после ошибки решение можно продолжить. При отсутствии непройденных задач разрешён повтор без изменения рейтинга. Dashboard показывает историю, успешность и тренировки по темам. Быстрый анализ партий и точность приблизительны; описание формулы и ограничений в `docs-review.md`.

Радар показывает девять направлений по аналогии с dashboard Lichess. Результативность вычисляется по формуле Lichess: средний рейтинг задач − 500 + 1000 × доля решений с первой попытки. В исходной выборке не все девять направлений размечены; для них отображается «—», а не выдуманные данные. Указатель ЯР/Эло следует настройке интерфейса, но это отдельные локальные очки пазлов (Elo K=32), а не ЯР или Эло партий; значения не конвертируются.

Текущая задача и пройденная часть решения сохраняются локально, в том числе после ошибки и перезагрузки. Просмотр предыдущих задач открывает их полное решение и не заменяет текущую задачу; оранжевый индикатор возвращает к ней. При переходе к другой теме новая задача выбирается намеренно. Ходы можно просматривать кнопками и стрелками клавиатуры; пока открыта прошлая позиция, ввод решения заблокирован до возврата к последней.

Полная история исходной партии загружается по ID через публичный Lichess Puzzle API. Перед отображением PGN проверяется позиция на `initialPly`; продолжение после исходной позиции не показывается и решение не раскрывается. При отсутствии сети, ограничении API или несовпадении позиции остаются доступными ходы самого пазла и отображается уведомление. Данные проверенной партии кешируются только на время текущей сессии страницы; для полной истории требуется подключение к Lichess.
