# shahmat

Одностраничный лендинг и авторизация на Supabase. Для локального запуска: `npm ci && npm run dev`; сборка: `npm run build`.

Публичный ключ Supabase в `app.js` предназначен для браузера. Приватный service-role ключ в приложение добавлять нельзя. Схема и правила RLS хранятся в `supabase/migrations/`.

Регистрация сейчас работает по email и паролю **без подтверждения почты** (Supabase `mailer_autoconfirm` включён). Адрес не подтверждается и его владение не проверяется; перед реальным запуском необходимо включить подтверждение и настроить отправку писем. Действующая единственная палитра — `monochrome`. При первом входе пользователь заполняет обязательное уникальное имя и может добавить описание.
