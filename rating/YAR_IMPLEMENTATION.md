# ЯР

- Четыре онлайн-режима: blitz, rapid, classical, daily; начальное значение в каждом — 1000. Отсутствующая запись считается 1000. Общий ЯР — среднее четырёх значений, а не отдельное сохраняемое число.
- На завершении онлайн-партии база атомарно обновляет оба значения в её режиме по модели Davidson (ν = 0.9), с K = 6 + 42/(1 + n/8) и пределами 0–2600. Вес блица 0.85, остальных режимов 1.0. Вес daily в исходном документе не задан, поэтому выбран вес классики.
- По UTC не более 25 рейтинговых партий в сутки на игрока и 3 с одним соперником. Если лимит достигнут у одного из участников, партия не меняет ЯР обоих. Боты не используют online_games и ЯР не меняют.
- По документу до 10 рейтинговых партий место не присваивается: такие игроки отображаются с прочерком после игроков с местами. На каждом экране не больше 100 игроков. Числа показываются с округлением до десятых, порядок рассчитывается по полной точности.
- Партии, завершённые до установки миграции, не пересчитываются. Для клиента доступны только имена и выбранные очки через yar_leaderboard; сами таблицы и история закрыты.
- Ежедневная нормировка среднего из RANKING_STRUCTURE.md пока не реализована: в документе не задано определение активного игрока и метод нормировки общего ЯР, который теперь является средним четырёх режимов. Её следует согласовать отдельно до применения, чтобы не изменять задним числом результаты реальных игроков произвольным способом.
- Выдача собирает значения из одной связи с таблицей рейтингов без размножения профилей по режимам; округление используется только для отображения. Клиент повторно использует результаты режима 15 секунд и объединяет одновременные запросы, не кэшируя их между аккаунтами.
- Анимации страницы вдохновлены Animata Fluid Tabs и Transaction List и реализованы средствами браузера без React; при `prefers-reduced-motion` отключаются.
