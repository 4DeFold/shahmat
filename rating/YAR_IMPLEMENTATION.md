# ЯР

- Три онлайн-режима: blitz, rapid, classical; начальное значение в каждом — 1000. Отсутствующая запись считается 1000. Общий ЯР — среднее трёх значений, а не отдельное сохраняемое число.
- На завершении онлайн-партии база атомарно обновляет оба значения в её режиме по модели Davidson (ν = 0.9), с K = 6 + 42/(1 + n/8) и пределами 0–2600. Вес блица 0.85, остальных режимов 1.0.
- По UTC не более 25 рейтинговых партий в сутки на игрока и 3 с одним соперником. Если лимит достигнут у одного из участников, партия не меняет ЯР обоих. Боты не используют online_games и ЯР не меняют.
- До 10 рейтинговых партий сохраняется статус калибровки, но по запросу владельца место в таблице показывается всем игрокам. Порядок определяется ЯР, независимо от калибровки. На каждом экране не больше 100 игроков. Числа показываются целыми, порядок рассчитывается по полной точности.
- Партии, завершённые до установки миграции, не пересчитываются. Для клиента доступны только имена и выбранные очки через yar_leaderboard; сами таблицы и история закрыты.
- Ежедневная нормировка среднего из RANKING_STRUCTURE.md пока не реализована: в документе не задано определение активного игрока и метод нормировки общего ЯР, который теперь является средним трёх режимов. Её следует согласовать отдельно до применения, чтобы не изменять задним числом результаты реальных игроков произвольным способом.
- Выдача собирает значения из одной связи с таблицей рейтингов без размножения профилей по режимам; округление используется только для отображения. Клиент повторно использует результаты режима 15 секунд и объединяет одновременные запросы, не кэшируя их между аккаунтами.
- Анимации страницы вдохновлены Animata Fluid Tabs и Transaction List и реализованы средствами браузера без React; при `prefers-reduced-motion` отключаются.

## Теневой Эло

- Параллельный Эло — отдельная оценка для каждого из трёх режимов; общий Эло для отображения, как и общий ЯР, равен среднему трёх режимов с начальными 1000 для отсутствующих. Это не конвертация между шкалами.
- С момента миграции те же допущенные рейтинговые онлайн-партии одновременно обновляют теневой Эло по классической формуле ожидания `1/(1+10^((Rсоперника−R)/400))`, K=20, без веса режима и без нормировки. Старые партии не пересчитаны; у всех старт 1000. История старых ЯР-партий не содержит Эло.
- Ранг, место, калибровка, ограничения и подбор определяются ЯР. Таблица остаётся упорядоченной по ЯР даже при отображении Эло. Настройка сохраняется в метаданных аккаунта и доступна в разных сеансах.
